# G-ONE & Wadada Support — Campaign Poster Generator

A digital grassroots mobilization platform completely cloned from [wadada-support.vercel.app](https://wadada-support.vercel.app/) with the **Prince Gowon Enenche (G-ONE)** House of Representatives campaign frame fully integrated.

---

## 🌟 Highlights & Features

- **Campaign Poster Generator Studio (`/generate`)**:
  - Interactive photo cropping with zoom (1x – 3x) and repositioning using `react-easy-crop`.
  - Seamless real-time live preview showing the cropped photo directly behind the official transparent cutout frame.
  - Multi-campaign frame selector:
    - **Prince Gowon Enenche (G-ONE)** — House of Representatives, Ankpa, Omala, Olamaboro Federal Constituency (Social Democratic Party - SDP).
    - **Sen. Ahmed Aliyu Wadada** — Nasarawa 2027 Gubernatorial Campaign.
  - Local Government Area (LGA) and Ward selection for constituency-level attribution.
  - Client-side high-resolution HTML5 Canvas rendering (1024x1024 / 1080x1080) with instant automated download.
  - Confetti celebration effect upon poster creation.

- **Success & Social Mobilization (`/generate/success`)**:
  - Poster preview with re-download button.
  - Direct 1-click sharing to WhatsApp, Facebook, X (Twitter), and clipboard link copy.

- **Supporters Wall (`/supporters`)**:
  - Real-time gallery displaying personalized posters generated by supporters.
  - Filterable by campaign (G-ONE / Wadada) and Local Government Area.

- **Campaign Statistics (`/statistics`)**:
  - Dynamic counters and progress metrics displaying poster engagement across Ankpa, Omala, Olamaboro, Lafia, Keffi, Karu, etc.

- **Homepage Experience (`/`)**:
  - Cinematic hero section with candidate backdrop, gradient overlays, and animated 3D poster showcase.
  - Dynamic LGA spotlight ticker.
  - 3-step walkthrough guide.
  - Full-width "IN GOD WE TRUST" brand banner.
  - Candidate and architecture profiles.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
